# Лабораторная работа 1

## Задание

Вариант 19. Создать сетку из изображений, которая адаптивно подстраивается под
размер экрана. На больших экранах колонок больше, чем на маленьких.

## Реализация

Страница содержит блок `.gallery` с шестью изображениями. Сетка сделана через
`display: grid`. По умолчанию одна колонка, при ширине от 700px — две колонки,
при ширине от 1000px — три колонки. Картинки растягиваются на ширину ячейки.

## Запуск

Откройте `index.html` в браузере.
