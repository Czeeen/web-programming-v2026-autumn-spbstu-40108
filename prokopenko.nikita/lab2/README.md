# Лабораторная работа 2

## Задание

Вариант 19. Реализовать функцию `generateParentheses(n)`, которая возвращает все
уникальные правильные комбинации скобок для `n` пар. Пример: для `n = 2`
результат `["(())", "()()"]`. Порядок элементов не важен.

## Реализация

Функция `generateParentheses` сначала собирает все строки из `(` и `)` длины
`n * 2`: на каждом шаге к уже собранным строкам дописывается либо `(`, либо `)`.
Затем функция `check` оставляет только правильные комбинации: счётчик растёт на
открывающую скобку и падает на закрывающую; он не должен уходить ниже нуля и в
конце должен быть равен нулю.

## Запуск

Импортируйте именованный export из `solution.js` как ES module:

```js
import {generateParentheses} from './solution.js';

console.log(generateParentheses(2));
```
