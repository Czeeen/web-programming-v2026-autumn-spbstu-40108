# Лабораторная работа 1

## Задание

Вариант 2. Сверстать «хлебные крошки» со следующими требованиями:

- основа структуры — список (`<ul>` / `<li>`);
- элементы списка — ссылки (`<a>`), кроме последнего;
- последний элемент — `<span>`;
- цвет ссылок — `#0056ff`;
- при наведении ссылка подчёркивается снизу;
- цвет `<span>` — `#333`;
- стрелки между элементами реализованы через псевдо-элемент `::after`.

## Реализация

Разметка построена на семантическом элементе `<nav>` с `<ul>` внутри. Каждый
элемент списка — `<li>`, содержащий либо ссылку `<a>`, либо `<span>` для текущей
страницы. Разделители `>` добавляются через
`.breadcrumbs__item:not(:last-child)::after`, что исключает лишний разделитель
после последнего элемента. Подчёркивание ссылки при наведении реализовано через
`text-decoration: underline` и `text-underline-offset`. Классы названы в
kebab-case по методологии БЭМ.

## Запуск

Откройте `index.html` в браузере (двойной клик или через Live Server).
