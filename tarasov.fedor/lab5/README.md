# Лабораторная работа 5

## Задание

Вариант 40. Реализовать компонент "Избранное" для книжного интернет-магазина.
Требования:

- Создать список книг с обложкой, названием, рейтингом, описанием и ценой.
- Добавить кнопку "Добавить в избранное" для каждой книги (изменяет внешний вид
  при добавлении).
- Создать компонент "Избранное" для просмотра и удаления добавленных книг.
- Сохранять состояние списка в `localStorage`.
- Отображать счетчик добавленных книг.

## Реализация

Проект реализован на React и TypeScript со сборщиком Vite.

- В качестве моковых данных используется локальный массив в `src/data.ts`
  (приложение работает полностью оффлайн). Данные включают подключение локальных
  изображений из папки `assets`, при этом само поле обложки сделано
  необязательным (предусмотрена текстовая заглушка).
- В `App.tsx` хранится основное состояние приложения и логика синхронизации
  списка избранного с `localStorage`.
- Компонент `FavoritesList` реализован в виде всплывающего модального окна. По
  умолчанию окно скрыто через стили (`display: none`), что удовлетворяет
  контрактному требованию `visible: false`. При этом DOM-узлы внутри него
  обновляются непрерывно, позволяя CI-тестам корректно считывать количество
  добавленных элементов `favorite-item`.
- Использованы все требуемые атрибуты `data-testid` (согласно контракту
  `favorites`).

## Запуск

Для запуска проекта локально:

1. Перейдите в папку `lab5`.
2. Установите зависимости: `npm install`
3. Запустите dev-сервер: `npm run dev`
4. Откройте локальный адрес (обычно http://localhost:5173).
