# Лабораторная работа 4

## Задание

**Вариант 40**. Необходимо создать класс `Travel` для учета путешествий со
следующими полями: `id` (число), `travelerName` (имя, строка),
`visitedCountries` (массив стран). Требуется реализовать методы добавления и
удаления страны из списка, геттер подсчета посещенных стран, а также 5 функций
для анализа коллекции путешествий (группировки, фильтрации и извлечения
уникальных значений).

## Реализация

- **Модель (`model.ts`)**: Содержит экспортированный класс `Travel` и набор
  функций для работы с массивом. В классе реализованы инкапсулированные методы
  добавления и удаления элементов.
- **Интерфейс (`main.ts` / `index.html`)**: Написан на Typescript и использует
  DOM API. Формы добавления, удаления путешествий и стран интегрированы.
  Состояние после любых изменений синхронизируется с `localStorage` для
  предотвращения потери данных при перезагрузке.
- **Асинхронность**: Операции создания и удаления оборачиваются в `Promise`
  через `setTimeout`, после чего происходит обновление DOM-дерева без полной
  перезагрузки страницы.

## Запуск

Скрипты написаны с использованием ESM и TypeScript. Для локальной разработки
используйте сборщик, например Vite:

```bash
npm init -y
npm install vite
npx vite
```
